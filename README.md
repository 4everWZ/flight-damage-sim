# Flight Damage Sim

A reusable WWII propeller-aircraft simulation core, developed and tested in Codex Cloud.

The core combines force-based flight dynamics, War Thunder-style mouse aim with full-authority per-axis keyboard maneuvering, and physical aerodynamic, structural, and control-system damage. The simulation must not substitute hit points, scripted wing destruction, or direct attitude changes for these systems.

The original FlightLab v0.1 specification has been recovered from the prior ChatGPT design conversation and will be preserved as the baseline before implementation. The current language choice is open to C++ and Python according to fit; the simulation core comes first, with a simple existing visualization/control tool integrated afterward.

Status: repository initialized. Original-spec import, technical experiments, and implementation are pending the dedicated Codex Cloud environment.
